# Student Task Management Application Student2

## Project Description
Student Task Manager is a simple web application built to demonstrate a real collaborative
Git and GitHub workflow. Users can add, display, complete, delete and search tasks.

## Features
- Add a task with title and description
- Display all tasks as cards
- Mark tasks as completed / undo
- Delete tasks
- Search tasks by title or description
- Responsive layout

## Technologies
HTML5, CSS3, JavaScript (vanilla), Git, GitHub

## Git Workflow
`main` is always stable. Every feature is built on its own branch, pushed to GitHub,
reviewed through a Pull Request by the partner, and then merged. Issues track the work.

## Branches
| Branch | Owner | Purpose |
|--------|-------|---------|
| main | Both | Stable code |
| feature/task-form | Student 1 | Task form + core logic |
| feature/task-style | Student 2 | Styling and responsive design |
| feature/task-search | Student 2 | Task search (Issue-based) |
| readme-title-s1 / readme-title-s2 | Both | Merge-conflict demonstration |

## Git Commands Demonstrated
`git init`, `status`, `add`, `commit`, `log`, `branch`, `switch`, `diff`, `diff --staged`,
`clone`, `remote -v`, `push`, `fetch`, `pull`, `merge`, `stash`, `restore`, `reset`,
`revert`, `show`, `blame`, `tag`

## GitHub Features Demonstrated
Repository, remotes, Issues, Pull Requests, code review, merging, linked issues
(`Closes #n`), tags, Releases, contributors graph.

## How to Run
1. Clone: `git clone <repository-url>`
2. Open `student-task-manager/index.html` in any browser. No build step needed.
